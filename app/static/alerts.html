웹 푸시 수신 설정

허용한 브라우저에 일반 알림을 보냅니다. 종목·금액·계정 정보는 잠금 화면에 표시하지 않습니다. 이메일과 별도 주기이며, 조건은 매일 점검합니다. 로그아웃 후에도 표시될 수 있으므로 공용 기기는 연결을 해제하세요. iPhone·iPad는 지원되는 홈 화면 웹 앱에서 이용합니다.

한국시간 오전 8시대에 점검합니다. 같은 채널에서 접수되었거나 결과가 불확실한 신호는 다시 보내지 않습니다. 당일 묶음 준비 후 주기 변경은 다음 예정일부터 적용될 수 있습니다.

    1. 종목 선택

    종목을 검색해 ‘종목 확인’을 누른 뒤 ‘확인한 종목 추가’를 누르세요. 미국은 SCHD, TQQQ, QQQI · 한국은 005930.KS, 247540.KQ 형식으로 입력하세요.

    아래에서 종목을 선택하면 같은 규칙을 일괄 등록할 수 있습니다. 가져와도 기존 자산은 변경되지 않습니다.

    가져올 보유 종목 선택

      제거하면 연결 규칙도 중지·보관됩니다. 종목을 다시 추가해도 규칙은 자동 복원되지 않습니다. 복원하려면 같은 조건을 입력하고 ‘보관된 동일 조건 재사용’을 선택하세요.

      최근 판정에는 정지된 규칙의 과거 결과도 포함됩니다. 현재 시세 상태가 아니며, 마지막 정상 평가 거래일은 아래 규칙별 상세에서 확인하세요.

      2. 조건 설정

      교차는 전일 선 이하에서 당일 선 위로, 또는 전일 선 이상에서 당일 선 아래로 이동했을 때입니다. 선에 닿거나 같은 방향에 머무르면 새 돌파가 아닙니다. EMA는 최초 종가에서 시작하며 볼린저 표준편차는 ddof=0입니다. 거래량 급증·신고저가·일간 급등락은 충족한 거래일마다 기록합니다.

      3. 내용 확인

      등록한 규칙과 최근 판정

      등록·재개·조건 변경 전에 끝난 신호는 메일로 보내지 않습니다. 정지 기간의 신호도 소급하지 않습니다.

        신호 이력

          채널별 발송 결과

          접수는 해당 공급자가 요청을 받았다는 뜻이며 수신함 도착·기기 표시와 다릅니다. 웹 푸시 결과가 불확실하면 중복을 막기 위해 자동 재전송하지 않습니다. 여러 브라우저 중 일부만 접수된 경우도 있으며 상세 이력은 화면에서 확인하세요.

            운영자 점검 상태

            최근 14회 점검의 작업·발송 집계이며 테스트 메일은 제외합니다. 접수와 실제 도착은 다릅니다. 처리시간은 초기화를 포함해 정상 기록된 호출의 누적 시간이며 강제 종료된 호출은 누락될 수 있습니다.

              알림 데이터 삭제

              관심종목·조건·신호와 발송 이력을 삭제하고 수신을 중지합니다. 대시보드의 보유자산·목표는 유지합니다.
