# 관심종목 Gmail 발송 운영 검토

기존 Gmail을 운영자 본인의 관심종목 메일에 재사용하고, 리밸런싱 메일은 기존 경로로 유지한다. GitHub Actions가 한국시간 08시대에 5분 간격으로 점검을 요청한다.

비판·가능성·외부인·확장성의 네 Orca 검토자가 참여했다. 비판 검토자는 최초 실행이 확인되지 않아 실패한 뒤 재시도했다. 검토에서 SMTP 수락 결과가 불확실하면 재전송 시 중복될 수 있고, 하루 한 번 점검으로는 5분 뒤 시세 재확인이 되지 않으며, 발송 준비 전 통합 전환 시 기존 메일이 중단될 수 있음을 확인했다.

Gmail은 운영자 본인에게만 발송하고, 접수 여부가 불확실한 발송은 자동 재전송하지 않는다. 기존 리밸런싱과 통합하지 않아 기존 메일 전환을 피한다. GitHub의 예약 실행은 지연이나 누락이 가능하므로 정시 발송 및 당일 재시도를 보장하지 않는다. SMTP는 수신·반송 웹훅을 제공하지 않으므로 접수와 실제 수신은 구분한다.
